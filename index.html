2Datos que tratamos

GS Residencial trata únicamente la información necesaria para registrar y autenticar al usuario, relacionarlo con su vivienda y permitir la integración con los servicios de HikConnect / HikCentral Connect.

Categoría Información Origen Finalidad
Cuenta Dirección de correo electrónico Usuario / registro existente en HikConnect Verificar que el usuario esté registrado en el entorno autorizado, crear su cuenta de GS Residencial e identificarlo al iniciar sesión.
Autenticación Credencial de acceso almacenada como hash de contraseña Generada por nuestra API a partir de la contraseña proporcionada por el usuario Autenticar de forma segura al usuario. La contraseña no se conserva en texto plano.
Residencia Nombre o identificador de la vivienda, calle, número de casa o información equivalente asociada a la vivienda HikConnect / HikCentral Connect Relacionar al usuario con la vivienda y con los accesos que le corresponden.
Integración Identificadores, recursos, permisos y otros datos técnicos asociados al entorno de HikConnect HikConnect / HikCentral Connect Permitir que la aplicación y nuestra API consuman los endpoints necesarios para operar las funciones de control de acceso.
Pases temporales Identificador interno, identificador del usuario, identificador único del pase temporal o código QR (temp_auth_id) y fecha de creación GS Residencial / HikConnect / HikCentral Connect Relacionar el pase temporal con el usuario y su autorización de acceso. El temp_auth_id identifica de forma única el QR o pase temporal generado por el sistema integrado.
Pagos Usuario asociado, fraccionamiento, mes, monto, ubicación del comprobante, estado, usuario administrador que valida y fechas de carga/validación Usuario / GS Residencial Registrar y validar administrativamente pagos del residencial.
Comprobante SPEI Imagen o archivo seleccionado voluntariamente por el usuario, que puede contener información personal y financiera mostrada en el comprobante bancario Usuario Permitir que administradores autorizados revisen y validen el pago correspondiente.
Importante: GS Residencial no solicita el nombre real ni los apellidos del residente como parte del registro descrito arriba. Los campos que identifican una casa o vivienda provienen del entorno de HikConnect y no corresponden al nombre personal del usuario. La aplicación no accede a la cámara, micrófono, ubicación GPS ni contactos como parte de su funcionamiento actual. Para adjuntar un comprobante de pago, el usuario selecciona voluntariamente una imagen o archivo específico desde su dispositivo; GS Residencial no examina ni recopila de forma general otras fotografías o archivos no seleccionados por el usuario.

3Cómo utilizamos la información

La información se utiliza para las siguientes finalidades:

  • Validación de registro: comprobar, mediante HikConnect / HikCentral Connect, que el correo electrónico esté asociado a un registro autorizado.
  • Creación y autenticación de cuenta: permitir el acceso a GS Residencial mediante el correo electrónico y la credencial protegida por hash.
  • Asociación con la vivienda: mostrar y utilizar la vivienda, casa o residencia correspondiente al usuario.
  • Control de acceso: consultar los recursos, identificadores y permisos necesarios para ejecutar las funciones habilitadas para el usuario.
  • Operación técnica: conservar la información de integración estrictamente necesaria para que los endpoints de HikConnect funcionen correctamente dentro de GS Residencial.
  • Pases temporales: generar, mostrar y relacionar códigos QR de acceso temporal con el usuario autorizado.
  • Validación de pagos: permitir al residente adjuntar un comprobante SPEI y a los administradores autorizados revisar su monto, periodo, estado y comprobante.

No vendemos los datos personales de los usuarios ni los utilizamos para publicidad.

4Integración con HikConnect / HikCentral Connect

GS Residencial utiliza servicios de HikConnect / HikCentral Connect, proporcionados por Hangzhou Hikvision Digital Technology Co., Ltd., para validar información existente en el entorno residencial y obtener los identificadores, recursos y permisos necesarios para las funciones de control de acceso.

Durante el registro, el correo electrónico proporcionado por el usuario se utiliza para verificar que exista un registro correspondiente dentro del entorno autorizado de HikConnect. Una vez validado, GS Residencial puede obtener información de la vivienda y datos técnicos asociados que son necesarios para operar la aplicación.

La información procesada directamente por Hikvision también está sujeta a sus propias políticas y condiciones. Puedes consultar la Política de Privacidad de Hikvision.

GS Residencial utiliza una cuenta propia para el inicio de sesión. El usuario no proporciona a GS Residencial las credenciales administrativas del entorno HikConnect del residencial.

5Almacenamiento y seguridad

Los datos necesarios para la cuenta y la integración se procesan mediante nuestra infraestructura de backend:

  • Backend API: servicio ApiHikConnect desarrollado para GS Residencial y desplegado en infraestructura de nube.
  • Base de datos: infraestructura basada en Supabase / PostgreSQL para la persistencia de los datos necesarios de la aplicación.
  • Comprobantes de pago: las imágenes o archivos de comprobantes cargados por el usuario se almacenan junto con una referencia de archivo para permitir su consulta durante el proceso de validación.
  • Aplicación móvil: determinados identificadores o datos de sesión/configuración pueden mantenerse localmente en el dispositivo cuando sean necesarios para el funcionamiento de la app.

Aplicamos medidas técnicas razonables para proteger la información, incluyendo:

  • Comunicación cifrada mediante HTTPS/TLS entre la aplicación y nuestra API.
  • Las contraseñas no se almacenan en texto plano; nuestra API conserva una representación protegida mediante hash.
  • Acceso restringido a los servicios y datos de backend necesarios para operar GS Residencial.
Ningún sistema conectado a Internet puede garantizar seguridad absoluta. Procuramos limitar el tratamiento y acceso a los datos a lo necesario para la operación del servicio.

6Conservación, acceso y eliminación de datos

El acceso a GS Residencial depende de que el correo electrónico del usuario continúe asociado a un registro válido y autorizado dentro del entorno correspondiente de HikConnect / HikCentral Connect. GS Residencial verifica esta relación para determinar si el usuario puede seguir utilizando las funciones de la aplicación.

Si la administración del residencial o HikConnect elimina, deshabilita o deja de reconocer la asociación del correo electrónico del usuario, el usuario perderá el acceso a GS Residencial, aunque pueda existir temporalmente información técnica o de autenticación previamente almacenada en nuestra infraestructura.

El usuario también puede solicitar la eliminación de los datos que se encuentren bajo control directo de Embaboo Software, incluyendo su correo electrónico, la credencial de autenticación almacenada mediante hash y, cuando corresponda, los identificadores o datos de integración asociados exclusivamente a su cuenta de GS Residencial. Para realizar esta solicitud puede comunicarse con embaboosoftware@gmail.com.

Importante: la eliminación de datos gestionados por GS Residencial no elimina ni modifica automáticamente el registro principal del residente dentro de HikConnect / HikCentral Connect. Del mismo modo, si el registro del usuario deja de existir o queda deshabilitado en HikConnect, GS Residencial dejará de autorizar su acceso a la aplicación.

Retención de comprobantes de pago: los comprobantes SPEI y el registro correspondiente en la tabla de pagos se conservan únicamente durante los tres meses más recientes. Al comenzar un cuarto mes, se elimina el archivo del comprobante y también el registro de base de datos correspondiente al mes más antiguo. De esta manera, GS Residencial mantiene únicamente los tres meses más recientes de comprobantes y registros asociados.

Conservaremos únicamente la información que debamos mantener por una obligación legal aplicable o por razones técnicas estrictamente necesarias durante el proceso de eliminación, y posteriormente será eliminada o desvinculada según corresponda.

7Proveedores, terceros y uso compartido de códigos QR

Para operar GS Residencial pueden intervenir los siguientes proveedores:

  • Hikvision (HikConnect / HikCentral Connect): validación del registro existente y operación de los recursos y permisos de control de acceso.
  • Render: infraestructura utilizada para alojar servicios de backend, cuando corresponda al despliegue vigente.
  • Supabase: servicios de base de datos e infraestructura utilizados por el backend.
  • Administración del residencial: administra la información y recursos del entorno residencial asociados al usuario dentro de HikConnect.

GS Residencial puede generar y mostrar pases temporales de acceso en formato QR. El pase visible puede incluir datos como nombre del visitante, PIN, número de usos permitidos, vigencia e identificadores del acceso. Nuestra base de datos no persiste necesariamente todos los datos visibles del pase; para su operación interna se conserva el identificador interno, user_id, el identificador único del QR o pase temporal (temp_auth_id) y la fecha de creación.

El usuario puede guardar el QR como imagen o compartirlo utilizando las funciones de compartir disponibles en Android. Esta acción es iniciada voluntariamente por el usuario.

GS Residencial no necesita leer la libreta de contactos ni inspeccionar otras fotografías del dispositivo para compartir el QR. Cuando el usuario elige compartir la imagen mediante otra aplicación (por ejemplo, mensajería o correo), el tratamiento que realice esa aplicación receptora queda sujeto a sus propias políticas y condiciones.

Guardar o compartir el QR implica exportar la imagen generada por GS Residencial al destino seleccionado por el usuario. La aplicación no utiliza esta función para publicidad ni para compartir automáticamente información con terceros.

GS Residencial también permite cargar voluntariamente un comprobante de pago SPEI para su revisión por usuarios administradores autorizados del residencial. El archivo puede contener información personal o financiera incluida por la institución bancaria, como nombre del ordenante, institución financiera, monto, referencias, clave de rastreo, RFC/CURP, CLABE, número de cuenta u otros datos visibles en el documento. GS Residencial no necesita extraer cada uno de esos campos por separado para realizar la validación; pueden formar parte de la imagen o archivo proporcionado por el usuario.

Los comprobantes se utilizan exclusivamente para validar administrativamente el pago correspondiente y pueden ser consultados por los usuarios administradores autorizados que realizan dicha validación.

No vendemos ni arrendamos los datos personales de los usuarios a anunciantes o terceros con fines comerciales.

9Menores de edad

GS Residencial no está diseñada específicamente para menores de edad. El acceso a la aplicación depende de que el correo electrónico esté previamente relacionado con un registro autorizado dentro del entorno residencial correspondiente.

Si un padre, madre o tutor considera que se han tratado indebidamente datos de un menor, puede comunicarse con embaboosoftware@gmail.com para solicitar su revisión.

10Funciones actualmente no habilitadas

La versión actual de GS Residencial no utiliza notificaciones push ni Firebase Cloud Messaging como parte de su funcionamiento disponible. Si en una versión futura se habilitan notificaciones u otras funciones que impliquen nuevos datos, permisos o proveedores, esta Política de Privacidad será actualizada antes o al momento de poner dichas funciones a disposición de los usuarios.
